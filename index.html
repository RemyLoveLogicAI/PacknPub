What init packs

      
Four files, zero runtime dependencies, and a package.json patch that never overwrites your choices.

      
    
        
  • .github/workflows/ci.yml
    Lint, test, build and tarball smoke on Linux, macOS and Windows across Node 20, 22 and 24.
    • 
        
  • .github/workflows/release.yml
    On a v*.*.* tag: verify, trusted npm publish, GitHub Packages, a checksummed GitHub Release, and a Homebrew bump.
    • 
        
  • scripts/verify-release.sh
    Local pre-publish gate: clean tree, tag match, secret scan, publint, attw, isolated install smoke.
    • 
        
  • scripts/homebrew/<bin>.rb
    Seed formula copied into your tap on the first release.
    • 
      

    


    

      
Three commands

      
Init scaffolds. Doctor scores readiness. Verify is the gate before anything ships.

      
packnpub init
Add CI, release workflow, verify script and Homebrew formula — then prints a live doctor scorecard.

      
packnpub doctor
Check Node, manifest, shebang, workflows, owner placeholders and README quickstart.

      
packnpub verify
Pack, install in an empty directory, and prove --version, --help and init --yes still work.
