PacknPub

Add a production-grade release pipeline to any Node package with one command.

$ npx packnpub init

Or with Homebrew: brew install RemyLoveLogicAI/tap/packnpub

What init adds

  • .github/workflows/ci.yml

    Lint, test, build and tarball smoke test on Linux, macOS and Windows across Node 20, 22 and 24.

  • .github/workflows/release.yml

    On a v*.*.* tag: verify, publish to npm with trusted publishing (no tokens), GitHub Packages, a GitHub Release with checksums, and a Homebrew formula bump.

  • scripts/verify-release.sh

    A pre-publish gate you can run locally before anything ships.

  • scripts/homebrew/<bin>.rb

    A seed formula, copied into your tap on the first release.

It also fills in missing package.json fields — repository, files, engines, publishConfig, scripts.verify — and never overwrites what you set. Re-running init is safe.

Three commands

packnpub init

Add CI, release workflow, verify script and Homebrew formula.

packnpub doctor

Check the package is ready to publish.

packnpub verify

Run the pre-publish gate: clean git tree, tag matches version, no secret-looking or source files in the tarball, bin shebang, publint, arethetypeswrong, and a full install-and-run smoke test in an empty directory.
